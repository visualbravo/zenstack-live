We're assuming you have a `docker-compose` file with a database service named `postgres` or `mysql`, which is configured with a `healthcheck`.

### Install LIVE

```package-install
@visualbravo/zenstack-live
```

</Step>
<Step>

### Edit `docker-compose`

You need Redis and Debezium. LIVE uses Redis as a database, not a cache, so you'll want to create a new Redis container even if your app already has one.

We have a pre-configured Debezium image called Zebezium that simplifies usage down to two environment variables: `DATABASE_URL` and `REDIS_URL`

```yaml title="docker-compose"
volumes:
  zenstack-live-redis-data:

services:
  zenstack-live-redis:
    image: redis:7.2
    volumes:
      - zenstack-live-redis-data:/data
    command: redis-server --maxmemory-policy noeviction --appendonly yes
    networks:
      - zenstack-live
    healthcheck:
      test: ['CMD-SHELL', 'redis-cli ping | grep PONG']
      interval: 5s
      timeout: 5s
      retries: 5

  zenstack-live-zebezium:
    image: visualbravo/zebezium
    restart: on-failure
    depends_on:
      # Uncomment the database you're using.

      # postgres:
      #   condition: service_healthy

      # mysql:
      #   condition: service_healthy

      zenstack-live-redis:
        condition: service_healthy
    environment:
      - DATABASE_URL=PUT_YOUR_DATABASE_URL_HERE # Don't forget to change this.
      - REDIS_URL=redis://zenstack-live-redis:6379
    networks:
      - zenstack-live
    healthcheck:
      test: ['CMD', 'curl', '-f', 'http://localhost:8080/q/health']
      interval: 5s
      timeout: 5s
      retries: 5
```

Now we'll setup your actual database.

<Tabs items={['Postgres', 'MySQL']}>
  <Tab value='postgres' class='px-2'>
    <div class='px-2 -my-2'>
      Postgres needs `wal_level` set to `logical`.
    </div>
    ```yaml title="docker-compose"
    services:
      postgres:
        # ...
        networks:
          - zenstack-live
        command:
          - 'postgres'
          - '-c'
          - 'wal_level=logical'
    ```
  </Tab>

  <Tab value='MySQL' class='px-2'>
    <div class='px-2 -my-2'>
      MySQL needs GTIDs enabled.
    </div>
    ```yaml title="docker-compose"
    services:
      mysql:
        # ...
        networks:
          - zenstack-live
        command:
          - --server-id=1
          - --binlog-format=ROW
          - --binlog-row-image=FULL
          - --gtid-mode=ON
          - --enforce-gtid-consistency=ON
    ```
  </Tab>
</Tabs>

Restart your containers.

</Step>

<Step>

### Open a stream

```typescript title="live.ts"
import { ZenStackClient } from '@zenstackhq/orm'
import { ZenStackLive, beforeAfter } from '@visualbravo/zenstack-live'
import { schema } from './zenstack/schema'

const client = new ZenStackClient(schema, ...)

const live = new ZenStackLive({
  client,

  redis: {
    url: process.env.REDIS_URL,
  },
})

const stream = live.stream({
  model: 'User',
  slug: 'log-user-events',
})

for await (const event of stream) {
  console.log(event.type, event.id, JSON.stringify(beforeAfter(event), null, 2))
}
```
</Step>
