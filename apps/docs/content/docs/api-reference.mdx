## ZenStackLive

The entry point. It connects to Redis as soon as it's created.

```typescript
import { ZenStackLive } from '@visualbravo/zenstack-live'

const live = new ZenStackLive({
  client,

  redis: {
    url: process.env.REDIS_URL!,
  },
})
```

### live.stream()

Creates a [`LiveStream`](#livestream). It throws if a filter is invalid or [unsupported](/docs/filtering-events#what-you-cant-filter-on).

```typescript
const stream = live.stream({
  model: 'User',
  slug: 'send-welcome-email',
  when: { created: {} },
})
```

<TypeTable
  type={{

      required: true,

    slug: {
      description: (

      ),
      type: 'string',

### live.prune()

Removes what's left behind by streams that are gone. See [Pruning](/docs/pruning).

```typescript
const report = await live.prune({
  olderThan: 7 * 24 * 60 * 60 * 1000,
  dryRun: true,
})
```

<TypeTable
  type={{
    olderThan: {
      description: "How long a stream has to be gone before it's removed, in milliseconds. Can't be shorter than `retention`.",
      type: 'number',
      required: true,
    },
    dryRun: {
      description: 'Reports what would be removed without changing anything.',
      type: 'boolean',
      default: false,
    },
  }}
/>

It returns a `LivePruneReport`:

<TypeTable
  type={{
    dryRun: { description: 'Whether this was a dry run.', type: 'boolean' },
    streams: { description: 'Streams that were removed.', type: 'PrunedStream[]' },
    consumers: {
      description: 'Consumers that were removed from streams that are still in use.',
      type: 'PrunedConsumer[]',
    },
    tables: {
      description: 'Tables dropped from the publication, along with their events.',
      type: 'PrunedTable[]',
    },
    unknownStreams: {
      description: 'Streams that were kept, because nothing shows when they were last used.',
      type: 'PrunedStream[]',
    },
    allTables: {
      description: 'Tables with no streams left, kept because the publication is `FOR ALL TABLES`.',
      type: 'PrunedTable[]',
    },
  }}
/>

```typescript
type PrunedStream = {
  slug?: string // Missing for streams last run by a version that didn't record them.
  model?: string
  redisStream: string
  consumerGroup: string
  lastSeenAt: Date | null
}

type PrunedConsumer = {
  name: string
  redisStream: string
  consumerGroup: string
  lastSeenAt: Date
}

type PrunedTable = {
  table?: { schema: string; name: string } // Missing if the table is no longer published.
  redisStream: string
  replicaIdentityFull: boolean
}
```

### live.disconnect()

Stops background trimming and closes the Redis connections. Streams from this instance stop reading, and may reject rather than end cleanly. Your ZenStack client is left open.

## Events

All events share these fields.

<TypeTable
  type={{
    type: {
      description: 'What happened. Use this to narrow the type.',
      type: "'created' | 'updated' | 'deleted'",
    },
    id: { description: "The event's unique ID. Stays the same on redelivery.", type: 'string' },
    transactionId: { description: 'The transaction that made the change.', type: 'string' },
    date: { description: 'When Debezium processed the change.', type: 'Date' },
  }}
/>

Each event type adds one field, holding the record. See [Reading Events](/docs/reading-events).

| Type                 | `type`    | Field                                |
| -------------------- | --------- | ------------------------------------ |
| `RecordCreatedEvent` | `created` | `created`                            |
| `RecordUpdatedEvent` | `updated` | `updated.before` and `updated.after` |
| `RecordDeletedEvent` | `deleted` | `deleted`                            |

## beforeAfter()

Gives every event the same `{ before, after }` shape. See [beforeAfter](/docs/reading-events#beforeafter).

