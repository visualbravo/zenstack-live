Run a single Debezium Server. These settings have to match what LIVE expects, because the names are built into it.

| Setting                                       | Value            | Why                                                         |
| --------------------------------------------- | ---------------- | ----------------------------------------------------------- |
| `DEBEZIUM_SOURCE_PUBLICATION_NAME`            | `zenstack_live`  | LIVE adds tables to this publication.                       |
| `DEBEZIUM_SOURCE_TOPIC_PREFIX`                | `zenstack.table` | LIVE looks for events in `zenstack.table.<schema>.<table>`. |
| `DEBEZIUM_SOURCE_PUBLICATION_AUTOCREATE_MODE` | `no_tables`      | Tables are published by your streams, not by Debezium.      |
| `DEBEZIUM_SOURCE_PLUGIN_NAME`                 | `pgoutput`       | The decoding plugin built into Postgres.                    |
| `DEBEZIUM_SOURCE_SNAPSHOT_MODE`               | `no_data`        | Existing rows aren't turned into events.                    |
| `DEBEZIUM_FORMAT_SCHEMAS_ENABLE`              | `false`          | LIVE reads plain events, without a schema attached.         |
| `DEBEZIUM_SINK_TYPE`                          | `redis`          | LIVE reads from Redis.                                      |

The offset and schema history settings in the [Quick Start](/docs/quick-start#start-postgres-debezium-and-redis) keep Debezium's state in Redis, so it doesn't need a volume of its own.

Leave these unset:

- **`table.include.list` and `schema.include.list`:** Anything they exclude never reaches your streams, and nothing reports it. LIVE decides what's captured through the publication.
- **Numeric and time handling, like `decimal.handling.mode` and `time.precision.mode`:** LIVE expects Debezium's defaults.

### Existing Publications

A publication that's `FOR ALL TABLES` keeps working, and every table stays captured. This includes `dbz_publication`, if you set up Debezium before LIVE managed the publication itself. Note that `prune` can't drop tables from one of these.
